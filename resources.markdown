## Compute Simulation Infrastructure

- **<a href="https://github.com/CSA-infra/RISCV-Scalable-Simulation-tutorial/tree/main" target="_blank" rel="noopener">RISC-V Scalable Simulation Tutorial</a>** — Getting started with gem5 for RISC-V simulations and ML workload analysis. Includes hands-on examples and slides.

- **<a href="http://sst-simulator.org/" target="_blank" rel="noopener">SST</a>** — The Structural Simulation Toolkit was developed to explore innovations in highly concurrent systems where the ISA, microarchitecture, and memory interact with the programming model and communications system.

- **<a href="https://github.com/sparcians/map/tree/master/sparta" target="_blank" rel="noopener">Sparta</a>** — A toolkit for modeling/simulation engineers to build CPU, GPU, and platform simulations.

- **<a href="https://accelergy.mit.edu/" target="_blank" rel="noopener">Accelergy</a>** — An energy/area estimation methodology for accelerators that allows design specifications comprised of user-defined high-level compound components and user-defined low-level primitive components, which can be characterized by external tools/plugins.

- **<a href="https://github.com/brendangregg/FlameGraph" target="_blank" rel="noopener">FlameGraph</a>** — Tool to visualize perf events.

- **<a href="https://chromium.googlesource.com/external/github.com/catapult-project/catapult/+/refs/heads/master/tracing/docs/getting-started.md" target="_blank" rel="noopener">Trace Viewer</a>** — This trace viewer from Chromium uses JSON-based trace logging for visualization. It has a relatively simple interface and a well-documented trace format.

- **<a href="https://github.com/microsoft/nni" target="_blank" rel="noopener">Microsoft NNI</a>** — This framework can be used for systematically performing Design Space Exploration (with relatively low effort), even though it is originally intended for neural network exploration.

## Command Line Programs

- **<a href="https://people.eecs.berkeley.edu/~alanmi/abc/" target="_blank" rel="noopener">ABC</a>** — A popular tool in the design automation community. It provides a comprehensive command-line system for logic synthesis as well as verification.

- **<a href="https://github.com/andreafrancia/trash-cli" target="_blank" rel="noopener">trash-cli</a>** — An alternative to _rm_ for deleting files on Linux. Deleted files are cached and can be retrieved if needed.

## Neural Network Tools

- **<a href="https://github.com/lutzroeder/netron" target="_blank" rel="noopener">Netron</a>** — A viewer for neural networks capable of visualizing models generated by a variety of deep learning frameworks, including ONNX, Caffe2, MXNet, etc.

## Python Libraries

- **<a href="https://igraph.org/python/doc/tutorial/tutorial.html" target="_blank" rel="noopener">igraph</a>** — A graph library with multiple bindings (Python, R, etc.). Well-documented and easy to pick up.

- **<a href="https://pypi.org/project/z3-solver/" target="_blank" rel="noopener">z3-solver</a>** — A theorem prover from Microsoft Research with support for bitvectors, booleans, arrays, floating point numbers, strings, and other data types. Great for solving SAT and other optimization problems.

- **<a href="https://dash.plotly.com/" target="_blank" rel="noopener">Dash</a>** — Can be used to build interactive graphs and visualizations from statistics generated by architectural simulators.
